# 💬 Application de Chat Android

Application mobile de **chat en ligne en temps réel**, développée avec **Android Studio** en **Java**, utilisant **Firebase** pour l’authentification, la base de données et les notifications push.

---

## 📝 Description
Cette application permet aux utilisateurs de communiquer instantanément via un système de messagerie en temps réel.  
Elle intègre une **authentification sécurisée**, la **gestion des utilisateurs** et l’**envoi de notifications** lors de la réception de nouveaux messages.

Le projet a été réalisé dans le cadre d’un **projet mobile académique**.

---

## 🚀 Fonctionnalités
- 🔐 Authentification des utilisateurs (**Firebase Authentication**)
- 💬 Messagerie instantanée en temps réel
- 🔔 Notifications push (**Firebase Cloud Messaging**)
- 👤 Gestion des profils utilisateurs
- 📱 Interface simple et intuitive
- ☁️ Synchronisation des messages en temps réel
